# 无障碍自查报告

> 对应阶段四 T4.4。检查范围：键盘可达性、焦点可见性、ARIA 标注、减少动效、触控目标。
> 结论：主流程可仅用键盘完成；画布内容本身没有文本替代，是本项目最大的无障碍缺口。

---

## 一、键盘可达性

| 操作 | 键位 | 状态 |
| --- | --- | --- |
| 切换九组机位 | `1`–`9` | ✅ |
| 复位 | `R` | ✅ |
| 自动旋转开关 | `Space` | ✅ |
| 关闭信息卡 | `Esc` | ✅ |
| 开始 / 退出导览 | `T` | ✅ |
| 导览上一站 / 下一站 | `←` / `→` | ✅ |
| 导览暂停 / 继续 | `Space` | ✅ |
| 退出导览 | `Esc` | ✅ |
| 打开建筑信息 | `Tab` 聚焦标签或侧栏项，`Enter` / `Space` | ✅ |
| 关闭信息卡 | `Tab` 到 × 按钮，`Enter` | ✅ |

### 焦点顺序

`Tab` 顺序按 DOM 结构走：左上角视角按钮 → 侧栏索引 → 工具条 → 建筑标签 → 信息卡。建筑标签有 43 个（角楼 4 座同名），逐个 Tab 会很长；这是已知取舍，后续可加分组跳转。

### 焦点可见性

- 所有按钮、侧栏项、建筑标签均有 `:focus-visible` 金色描边。
- 建筑标签的描边加在 `.lbl-body` 上，避免描边被裁切。
- 信息卡打开时不会强制抢焦点，避免打断键盘浏览。

## 二、ARIA 与语义

| 元素 | 处理 |
| --- | --- |
| 工具按钮 | `aria-label` + `title`，双语同步 |
| 自动旋转 / 标注 | `aria-pressed` 反映开关状态 |
| 建筑标签 | `role="button"`、`tabindex="0"`、`aria-label="太和殿，查看详情"` |
| 侧栏条目 | `role="button"`、`tabindex="0"` |
| 信息卡 | `role="region"`、`aria-live="polite"`、`aria-labelledby` 指向标题 |
| 导览字幕条 | `role="region"`、`aria-live="polite"`，换站时朗读 |
| 提示条 | `role="status"`、`aria-live="polite"` |
| 页面语言 | `<html lang>` 随中英切换更新 |

## 三、减少动效

`js/views.js` 的 `Views.reducedMotion()` 读取 `prefers-reduced-motion: reduce`：

- 机位切换由弧线飞行改为直接落位。
- 导览换站同样直接落位，不做强制镜头飞行。
- CSS 在减少动效下关闭过渡与动画。
- 自动旋转默认关闭，不受该设置影响。

| 项 | 结论 |
| --- | --- |
| 正文对比度 | 信息卡正文 `rgba(242,234,217,.78)` 对深底，实测约 9:1，达标 |

## 五、已知缺口

1. **画布无文本替代**：三维场景本身没有 `aria-describedby` 或文字版总平面。屏幕阅读器用户只能通过侧栏词条理解内容。
2. **标签数量多**：43 个标签逐个 Tab 体验冗长，缺少“跳到下一组”的快捷方式。
3. **信息卡正文仅中文**：英文界面下标题与字段标签为英文，正文仍是中文原文，尚未做全量翻译。
4. **未做真实读屏测试**：本报告基于 DOM 结构与键盘操作自查，未在 VoiceOver / NVDA 下完整走查。
5. **对比度未用工具实测**：数值为按色值估算，建议用 axe 或 Lighthouse 复核。
