# 无障碍自查报告

> 对应 v2.0 的无障碍改造，并在 v2.1 新增搜索、已阅、指北针与沉浸模式后复核。
> 检查范围：键盘可达性、焦点可见性、ARIA 标注、减少动效、触控目标。
> 结论：主流程可仅用键盘完成；画布内容本身没有文本替代，是本项目最大的无障碍缺口。
> 数字口径：侧栏 72 条（`node tools/stats.js`），建筑标签 75 个（角楼 4 座同名，标签不去重）。

### 焦点顺序

`Tab` 顺序按 DOM 结构走：左上角视角按钮 → 侧栏（搜索框 → 72 条索引项）→ 工具条 → 日照条与播放键 → 建筑标签 → 指北针 → 信息卡。建筑标签有 75 个（角楼 4 座同名），逐个 Tab 会很长；这是已知取舍，后续可加分组跳转。

### 焦点可见性

- 所有按钮、侧栏项、指北针、建筑标签均有 `:focus-visible` 金色描边；搜索框用金色边框 + 背景加深表示聚焦（`outline` 已关闭，避免双线）。
- 建筑标签的描边加在 `.lbl-body` 上，避免描边被裁切。
- 信息卡打开时不会强制抢焦点，避免打断键盘浏览。
- `H` 沉浸模式下界面元素同时设 `visibility: hidden`，焦点不会停在看不见的控件上；再按 `H` 即恢复。

## 二、ARIA 与语义

| 元素 | 处理 |
| --- | --- |
| 工具按钮 | `aria-label` + `title`，双语同步 |
| 自动旋转 / 标注 / 昼夜流转 | `aria-pressed` 反映开关状态 |
| 建筑标签 | `role="button"`、`tabindex="0"`、`aria-label="太和殿，查看详情"` |
| 侧栏条目 | `role="button"`、`tabindex="0"`；已阅项加 `✓`，不计入无障碍名 |
| 搜索框 | `type="search"` + `aria-label`，随语言切换 |
| 已阅计数 | `title` 说明"已阅词条 / 总数"，纯展示不设 `aria-live`（避免每次翻词条都朗读） |
| 指北针 | `role="button"`、`tabindex="0"`、`aria-label` 说明"点击使视角朝向正北" |
| 信息卡 | `role="region"`、`aria-live="polite"`、`aria-labelledby` 指向标题 |
| 导览字幕条 | `role="region"`、`aria-live="polite"`，换站时朗读 |
| 提示条 | `role="status"`、`aria-live="polite"` |
| 页面语言 | `<html lang>` 随中英切换更新 |

## 三、减少动效

`js/views.js` 的 `Views.reducedMotion()` 读取 `prefers-reduced-motion: reduce`：

- 机位切换由弧线飞行改为直接落位。
- 导览换站同样直接落位，不做强制镜头飞行。
- CSS 在减少动效下关闭过渡与动画（含新加的搜索框、指北针与沉浸模式过渡）。
- 自动旋转默认关闭，不受该设置影响。
- **昼夜流转不自动开始**：它只由用户点按或 `?play=1` 触发，减少动效用户不会被强制拉进动画。水面波纹属环境动效，跟随日照联动，无法单独关闭；如需完全静止可用 `?still=1`。

## 五、已知缺口

1. **画布无文本替代**：三维场景本身没有 `aria-describedby` 或文字版总平面。屏幕阅读器用户只能通过侧栏词条理解内容。
2. **标签数量多**：75 个标签逐个 Tab 体验冗长，缺少"跳到下一组"的快捷方式。
3. **信息卡正文仅中文**：英文界面下标题与字段标签为英文，正文仍是中文原文，尚未做全量翻译。
4. **搜索无结果时不朗读**：`#no-result` 未设 `aria-live`，读屏用户需要自行察觉列表变空。
5. **未做真实读屏测试**：本报告基于 DOM 结构与键盘操作自查，未在 VoiceOver / NVDA 下完整走查。
6. **对比度未用工具实测**：数值为按色值估算，建议用 axe 或 Lighthouse 复核。

## 六、复核方式

```bash
# 键盘：只用 Tab / Enter / 方向键，从加载完成走到打开一条词条
open index.html

# 新控件：Tab 到搜索框输入"太"，Esc 清空；Tab 到指北针按 Enter；按 H 隐藏再恢复
# 减少动效：macOS 系统设置 → 辅助功能 → 显示 → 减弱动态效果
# 或在 Chrome 启动参数加 --force-prefers-reduced-motion
```
