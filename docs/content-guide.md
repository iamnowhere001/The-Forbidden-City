# 内容规范与匾额校核

> 适用于 `js/data/info.js`。目标不是写百科，而是让每一条都能被核查、不夸大、不虚构。

---

## 一、词条字段

| 字段 | 必填 | 说明 |
| --- | --- | --- |
| `name` | 是 | 中文名，必须与匾额、侧栏一致 |
| `en` | 是 | 英文名，采用故宫官方常用的意译 |
| `cat` | 是 | 前朝 / 后寝 / 东路 / 西路 / 城防 |
| `year` | 是 | 始建或重建年代，格式见下 |
| `form` | 是 | 屋顶形制与院落格局 |
| `scale` | 否 | 面阔、进深、通高等；不确定的标“示意” |
| `status` | 否 | 现状用途，只在有把握时填写 |
| `desc` | 是 | 史实说明，40–120 字，重点殿宇 80 字以上 |
| `note` | 否 | 考据说明、争议点、示意标注 |

### 写作约定

- **年代格式**：`明永乐十八年（1420）`；重建用 `明永乐十八年（1420）／清康熙三十四年（1695）重建`。
- **术语统一**：面阔、进深、重檐、庑殿、歇山、攒尖、盝顶、十字歇山（释义见下）。
- **不写无法核查的数字**。场景是示意复原，不是测绘成果；六宫面阔统一标“（示意）”。
- **有争议的内容进 `note`**，不塞进正文伪装成定论。
- **不写“最美”“最大”之类营销词**。太和殿“现存最大木结构殿宇”属学界通说，可保留。

## 二、术语表

| 术语 | 含义 |
| --- | --- |
| **面阔** | 建筑正面的开间总宽，间数即开间数。 |
| **进深** | 垂直于面阔方向的深度，常以椽架计。 |
| **重檐** | 两层屋檐，下层檐环绕屋身，等级高于单檐。 |
| **庑殿** | 四面坡、一条正脊四条垂脊，官式建筑中等级最高。 |
| **歇山** | 上部两面坡、下部四面坡，一条正脊、四条垂脊、四条戗脊。 |
| **攒尖** | 各坡向中心汇聚于宝顶，无正脊，多用于方亭、圆亭。 |
| **盝顶** | 顶部为平顶，四周做坡檐。 |
| **十字歇山** | 两个歇山顶十字相交，角楼即此形制。 |
| **举折** | 屋面从檐口到屋脊由缓渐陡的凹曲线。 |
| **翼角起翘** | 屋檐转角处向上翘起，是明清官式建筑的典型特征。 |
| **推山** | 庑殿顶将正脊向两端延伸、使垂脊转折的处理。 |

## 五、考据边界

1. 本项目的三维模型是**示意复原**，不是测绘成果。开间数、院落尺寸与真实建筑存在偏差。
2. 词条只写通说，不采用孤证；有争议的细节写进 `note`，例如长春宫《红楼梦》壁画的作者与题材至今仍有讨论。
3. 现状用途会随展览调整而变化，`status` 只写相对稳定的信息（如“原状陈列”“参观出口”）。
4. 不引用具体书目页码，避免制造“精确引用”的假象；如需学术引用，应另行核对原书。
